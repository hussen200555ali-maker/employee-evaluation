# التحديث البصري

يعتمد التحديث اتجاه **واجهة مؤسسية هادئة**: أخضر داكن مائل للفيروز للقرارات والإجراءات، خلفية عاجية خفيفة، ذهب هادئ للإبراز، وخط Cairo المحلي. يحافظ التصميم على كثافة معلومات مناسبة للنظام الإداري من دون بطاقات مبالغ في تدويرها أو ألوان متوهجة.

تشمل طبقة `public/css/modern-ui.css` القالب العام والتنقل والقوائم والجداول والنماذج وتخطيط الهاتف، بينما أضيفت تهيئة موحدة لشاشة تعبئة التقييم ولوحة التحكم ومساحة Excel. تظل عناصر التنقل والإجراءات محكومة بفحوص الصلاحيات الأصلية في PHP.

أثناء المعاينة المحلية المباشرة، يحتاج خادم PHP إلى جذر موقع يطابق مسار `APP_URL/public` حتى تقدّم ملفات CSS المحلية. هذا قيد في إعداد المعاينة المؤقتة فقط؛ في تثبيت XAMPP المعتاد يكون `employee-evaluation/public` ضمن المسار ذاته المقصود في القالب.
