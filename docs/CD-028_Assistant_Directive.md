### أ. بيانات الموظفين (5 موظفين)
أنشئ 5 موظفين بأسماء عربية واقعية (عبر `/employees/create` أو SQL):
- عبدالله محمد العتيبي — مدير قسم العمليات
- نورة سعد القحطاني — محللة بيانات
- خالد فهد الدوسري — مهندس نظم
- سارة عبدالعزيز الحربي — أخصائية موارد بشرية
- فهد ناصر المطيري — محاسب أول

1. أنشئ catalog: "إدارة المشاريع"

3. أضف 3 مشاركين (عبدالله، نورة، خالد) في `course_participants`

### ج. التقييمات
- **عبدالله:** تقييم سنوي (قالب 1) — املأ درجات واقعية
- **نورة:** تقييم سنوي (قالب 1) + تقييم وصفي للدورة (قالب 2)
- **خالد:** تقييم مهاري (قالب 4) + تقييم رقمي للدورة (قالب 3)

### د. التقارير
- ولّد تقرير PDF + Excel + Word لعبدالله (سنوي فقط) أو نورة (سنوي + دورة)
