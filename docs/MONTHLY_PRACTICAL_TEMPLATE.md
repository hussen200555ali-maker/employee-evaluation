# قالب التقرير الشهري لاستمارة تقييم الأداء العملي الشهري

## المصدر
- الملف الورقي: `docs/التقرير استمارة التقييم  الشهري العملي.xlsx` — ورقة `تقييم الأداء العملي الشهري` — طباعة `A1:W45` — `A3` افقي 35%
- تاريخ الانشاء في النظام: 2026-09-01 — `id=2`

## الفكرة
- منشئ القوالب يبني فقط المعايير والاقسام (الاسم والاوزان والخيارات)
- البيانات الشخصية (الاسم/الرقم الوظيفي/الفرع/القسم) وبيانات المقيم تؤخذ تلقائيا من واجهة بدء تقييم موظف جديد (جدول `evaluations`)

## الهيكل المنشأ (مطابق لمصطلحات Excel حرفيا عبر قسم تقدير)
| المعيار | الوزن | القسم | الوزن داخل المعيار | الخيارات (تقدير) |
|---|---|---|---|---|
| أولاً: تطبيق المهام اليومية | 40% | الإلتزام بالزي الرسمي | 33.34% | طبق:100 / لم يطبق:0 |
|  |  | التوجيهات المقدمه له | 33.33% | طبق:100 / لم يطبق:0 |
|  |  | تعامله مع الوثائق المقدمه له | 33.33% | قرأ:100 / لم يقرأ:0 |
| ثانياً: رفع التقرير الأسبوعي | 30% | الأسبوع الأول | 25% | رفع:100 / لم يرفع:0 |
|  |  | الأسبوع الثاني | 25% | رفع:100 / لم يرفع:0 |
|  |  | الأسبوع الثالث | 25% | رفع:100 / لم يرفع:0 |
|  |  | الأسبوع الرابع | 25% | رفع:100 / لم يرفع:0 |
| ثالثاً: رفع التقرير الشهري | 30% | الرفع | 50% | رفع:100 / لم يرفع:0 |
|  |  | استخدام النموذج الرسمي | 50% | إلتزم:100 / لم يلتزم:0 |

- مجموع المعايير = 100% — كل معيار مجموع اقسامه = 100% (يحقق `validateWeights`)
- ملاحظات عامة والملحق (صورة الاستمارة) = `allow_notes` على الاقسام الثلاثة الاولى

## الحساب
- `normalized_score` لكل قسم تقدير = القيمة المختارة مباشرة (100 او 0)
- درجة المعيار = Σ(normalized × section_weight/100)
- الدرجة النهائية = Σ(درجة المعيار × criterion_weight/100)
