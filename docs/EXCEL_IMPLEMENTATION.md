# تنفيذ Excel في المشروع المرفق

## ما أضيف

أضيفت خدمة `EvaluationExcelService` ومسارات ووحدة تحكم وواجهة استيراد. ينزّل المقيّم قالب XLSX يتضمن ورقة إدخال، وورقة معرفات داخلية مخفية ومحميّة، وورقة تعليمات. لا يجلب القالب إلا التقييمات ذات حالة `draft` التي يكون الموظف المسجل كمقيّم مسؤولاً عنها.

يعالج الاستيراد على مرحلتين. ترفع المرحلة الأولى الملف وتفحص الصيغة والحجم وأوراق العمل والمعرفات وتخصيص المقيّم والقالب ورمز الموظف والبند ونوع القيمة، ثم تنشئ دفعة معاينة وسجل أخطاء للصفوف. لا تسمح المرحلة الثانية بالالتزام إذا وُجد أي خطأ. عند الالتزام يعاد التحقق داخل معاملة قاعدة بيانات واحدة، وتحفظ الإجابات وتحسب الدرجة النهائية وتسجل عملية التدقيق.

| الملف | الغرض |
|---|---|
| `database/migrations/20260824_excel_import.sql` | جداول الدفعات والصفوف وسجل الأخطاء. |
| `app/Services/EvaluationExcelService.php` | تصدير القالب، المعاينة، التحقق، الالتزام، والحساب. |
| `app/Controllers/EvaluationExcelController.php` | حراسة الصلاحية وCSRF ومسارات التدفق. |
| `app/Views/evaluations/excel_import.php` | شاشة رفع الملف والمعاينة وتأكيد الالتزام. |
| `tests/ExcelWorkflowSmoke.php` | اختبار دخان محفوظ للسيناريو السليم ورفض الصيغ. |

## التثبيت على XAMPP

نفّذ من جذر المشروع بعد ضبط `config/database.php` لاتصال XAMPP المحلي:

```bash
composer install --no-dev --optimize-autoloader
mysql -u root -p employee_evaluation_mvc < database/migrations/20260824_excel_import.sql
```

بعد تسجيل دخول حساب مرتبط بموظف مقيّم يملك `evaluations.fill`، افتح `/evaluations` ثم رابط **استيراد وتصدير Excel**. لا يظهر الرابط لمن لا يملك الصلاحية، كما تفرض المسارات التحقق نفسه خادمياً.

## دليل التحقق المنفذ

تم تشغيل فحص صياغة جميع ملفات `app` و`routes` و`tests` بنجاح. كما مرّ `tests/ExcelWorkflowSmoke.php` على قاعدة اختبار محلية معزولة، وتحقق من تصدير ورقة المعرفات المخفية، معاينة XLSX سليم، التزام ذري يحفظ القيمة والدرجة الموحدة، ورفض خلية تبدأ بصيغة Excel.

أضيف `phpoffice/phpspreadsheet` إلى Composer، ثم حدّث اعتماد PHPUnit التطويري إلى `11.5.56` بعد أن أظهر التدقيق مستشاراً أمنياً في النسخة السابقة. انتهى `composer audit` بعد التحديث دون أي مستشار أمني معروف.

> اختبارات المشروع القديمة تعمل عبر `tests/runner.php` وليست PHPUnit. فيها أعطال سابقة غير مرتبطة بوحدة Excel، منها مخرجات مبكرة في `config/config.php` وغياب `errors/404`. لم يُقدَّم نجاح هذه الاختبارات على أنه تحقق كامل للنظام.

## قيود ما زالت مفتوحة

هذا المشروع المرفق لا يملك نموذج النطاق متعدد المستويات أو دورات التقييم أو حالات سير العمل المطلوبة في SRS v2.2. لذلك عزل Excel الحالي قائم على `evaluator_employee_id` وحالة `draft` وصلاحية `evaluations.fill`، وليس بديلاً عن استكمال RBAC والنطاقات والدورات في بقية التطبيق. كما يجب مراجعة مخطط SQL المصدر قبل الإنتاج؛ استيراده في قاعدة اختبار أظهر مرجع مستخدم غير متسق يمنع إنشاء أحد مفاتيح `users.employee_id` الخارجية إذا فُعّلت القيود أثناء الاستيراد.
