# مصفوفة لوحات التحكم حسب الدور

يتحكم الخادم في بيانات اللوحة أولاً، ثم تتحكم الواجهة في المكونات المرئية على أساس الصلاحيات نفسها. لا يعتمد أي مقياس أو رسم بياني على تصفية المتصفح فقط.

| شخصية اللوحة | شرط التفعيل | نطاق بيانات التقييم | المكونات الأساسية |
|---|---|---|---|
| مدير النظام | دور `Admin` أو `reports.view.all` | المؤسسة المتاحة في قاعدة البيانات | حجم التقييمات، حالة الإنجاز، متوسط النتيجة، اتجاه شهري، توزيع النتائج، آخر النشاط، اختصارات الإدارة. |
| الموارد البشرية | `employees.view` مع صلاحيات التقارير | المؤسسة المتاحة | الموظفون، التقييمات، الإكمال، الأداء، الاتجاه والتوزيع، إدارة الموظفين والتقارير. |
| مدير الفريق | `reports.view.team` | الموظفون الذين يشير `manager_id` لديهم إلى موظف المستخدم | ملخص الفريق، المهام المفتوحة، الأداء، اتجاه الفريق، قائمة الأنشطة. |
| المقيّم | `evaluations.fill` وحساب مرتبط بموظف | التقييمات التي يكون فيها `evaluator_employee_id` موظف المستخدم | المسودات المسندة، المكتمل، متوسط النتائج، حالة المهام، اتجاه التقييمات، اختصار مركز Excel. |
| مستخدم محدود | بقية الحسابات | التقييمات التي يكون المستخدم هو الموظف المقيم | ملخص شخصي محدود ونشاطه فقط، ولا تظهر إدارة أو تقارير مؤسسية. |

> بنية المشروع المرفق لا تحتوي بعد على جداول نطاقات تنظيمية مستقلة. لذلك يطبق مستوى الفريق عبر `employees.manager_id`، ويطبق مستوى المقيّم عبر `evaluations.evaluator_employee_id`. لا ينبغي توسيع هذا النطاق إلى الفروع أو الأقسام من الواجهة قبل استكمال نموذج النطاق الخادمي في قاعدة البيانات.
