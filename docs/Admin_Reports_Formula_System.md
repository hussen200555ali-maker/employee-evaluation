# نظام التقارير الإدارية - الصيغ الحسابية والأقسام التلقائية

> آخر تحديث: 2026-09-09
> الإصدار: 2.0

---

## نظرة عامة

يهدف هذا النظام إلى دعم التقييمات الإدارية والتنظيمية عبر الباني الموحد، مع إضافة three ميزات رئيسية:
1. **أقسام الصيغ الحسابية** - إجراء حسابات تلقائية بين أقسام القالب
2. **الأقسام التلقائية** - سحب بيانات مباشرة من النظام دون إدخال يدوي
3. **حقول مساعدة للحسابات** - مدخلات رقمية تُستخدم في الصيغ دون تأثير على الوزن

---

## أنواع الأقسام السبعة

| النوع | المعرّف | يُحتسب في الوزن؟ | الإدخال | مثال |
|-------|---------|-----------------|---------|------|
| نسبة مئوية | `percentage` | ✅ نعم | المستخدم يدخل (0-100) | 85% |
| رقمي | `numeric` | ✅ نعم | المستخدم يدخل بالنطاق | عدد الموظفين |
| تقدير | `grade` | ✅ نعم | قائمة منسدلة | ممتاز/جيد |
| نعم/لا | `boolean` | ✅ نعم | أزرار راديو | هل يوجد تقرير؟ |
| صيغة حسابية | `formula` | ✅ نعم | حساب تلقائي (readonly) | =(B1+C1)/2 |
| تلقائي | `auto` | ✅ نعم | من النظام (readonly) | actual_force |
| **حقل مساعد** | `helper` | ❌ لا | المستخدم يدخل رقم | 150 |

---

## النوع الجديد: حقل مساعد للحسابات (`helper`)

### ما هو؟
حقل رقمي يدخله المستخدم لاستخدامه كمتغير في الصيغ الحسابية. **لا يُحتسب في وزن الاستمارة** ولا يؤثر على النتيجة النهائية.

### متى نستخدمه؟
- القوة الفعلية ليست مكتملة في النظام ويحتاج المدير لإدخالها يدوياً
- أي قيمة رقمية يجب استخدامها في صيغة حسابية لكن لا تريد تأثيرها على النتيجة

### مثال عملي:
```
المعيار: "تحليل الأداء" (وزن 100%)
  ├── A1: "الإنجاز" (percentage، وزن 40%) → 85
  ├── B1: "الجودة" (percentage، وزن 35%) → 90
  ├── C1: "عدد الموظفين" (helper) → 150  ← لا يُحتسب!
  ├── D1: "الالتزام" (percentage، وزن 25%) → 78
  └── E1: "النتيجة لكل موظف" (formula: =(A1+B1+D1)/C1) → 1.75
```

### ملاحظات مهمة:
- `helper` لا يظهر في حقل الوزن في الباني (إشعار: "الحقل المساعد لا يُحتسب في وزن الاستمارة")
- `helper` يحصل على عمود خاص في مصفوفة الصيغ (A, B, C, D...)
- يمكن الرجوع إليه في الصيغ بشكل مباشر مثل أي قسم آخر
- في العرض يظهر بلون خاص (رمادي) مع تسمية "(مساعد)"

## نظام مراجع الأعمدة

### البنية
كل قسم يحصل على معرف فريد `حرف+رقم`:

```
المعيار 1:
  ├── القسم 1 → A1
  ├── القسم 2 → B1
  ├── القسم 3 → C1
  └── القسم 4 → D1

المعيار 2:
  ├── القسم 1 → A2
  ├── القسم 2 → B2
  └── القسم 3 → C2
```

### أمثلة على الصيغ:

| الصيغة | الوصف | النتيجة |
|--------|-------|---------|
| `=(B1+C1+D1)/3` | متوسط 3 أقسام | (85+90+78)/3 = 84.33 |
| `=(A1+B1+D1)*100` | مجموع مضاعف | (85+90+78)*100 = 25300 |
| `=A1/C1` | نسبة (قسم helper) | 85/150 = 0.57 |
| `=IF(A1>80,"جيد","ضعيف")` | شرطي | "جيد" |
| `=SUM(B1:B5)` | مجموع نطاق | مجموع 5 أقسام |
| `=AVG(B1:B5)` | متوسط نطاق | متوسط 5 أقسام |
| `=TOTAL()` | مجموع العمود | مجموع كل القيم |
| `=AVERAGE()` | متوسط العمود | متوسط كل القيم |

### الدوال المدعومة:

| الدالة | الوصف | المثال |
|--------|-------|--------|
| `SUM(range)` | المجموع | `=SUM(B1:B5)` |
| `AVG(range)` | المتوسط | `=AVG(B1:B5)` |
| `MIN(range)` | الأدنى | `=MIN(B1:B5)` |
| `MAX(range)` | الأعلى | `=MAX(B1:B5)` |
| `COUNT(range)` | العدد | `=COUNT(B1:B5)` |
| `IF(cond,t,f)` | شرطي | `=IF(B1>80,"جيد","ضعيف")` |
| `AND(c1,c2)` | AND شرطي | `=AND(B1>80,C1>80)` |
| `OR(c1,c2)` | OR شرطي | `=OR(B1>80,C1>80)` |
| `TOTAL()` | المجموع الكلي | `=TOTAL()` |
| `AVERAGE()` | المتوسط الكلي | `=AVERAGE()` |

## تدفق العمل الكامل

### 1. إنشاء القالب (الباني)

```
المدير يفتح الباني
  ↓
يختار نوع القالب: "إداري/تنظيمي"
  ↓
يُنشئ معايير وأقسام
  ↓
يُضيف أقسام صيغة حسابية (formula)
  ├── يحدد الصيغة: =(B1+C1+D1)/3
  ├── يحدد الوصف: "متوسط التقييمات"
  └── يحدد: للقراءة فقط (readonly)
  ↓
يُضيف أقسام تلقائية (auto)
  ├── يختار المصدر: actual_force
  └── يحدد: للقراءة فقط (readonly)
  ↓
يُضيف حقول مساعدة (helper)
  ├── يحدد: "عدد الموظفين"
  └── النظام: لا يُحتسب في الوزن
  ↓
يحفظ القالب
```

### 2. إنشاء التقرير

```
المستخدم يفتح صفحة إنشاء تقرير
  ↓
يختار القالب الإداري
  ↓
يُظهر النظام جميع الأقسام كحقول إدخال:
  ├── أقسام عادية: حقول إدخال قابلة للتعديل
  ├── حقول مساعدة: حقول رقمية (رمادي) ← لا تؤثر على الوزن
  ├── أقسام صيغة: حقول readOnly مع نتيجة محسوبة تلقائياً
  └── أقسام تلقائية: حقول readOnly تُملأ من النظام
  ↓
المستخدم يُدخل القيم في الأقسام العادية والمساعدات
  ↓
النظام يحسب الصيغ فوراً (JavaScript)
  ↓
يحفظ التقرير مع جميع القيم المحسوبة
```

### 3. عرض النتائج

```
المستخدم يفتح صفحة العرض
  ↓
النظام يعرض:
  ├── البيانات الأساسية (العنوان، الفترة، الحالة)
  ├── بيانات القوة (فعلية، مطبقه، نسبة المطابقة)
  ├── نتائج التقييم المحسوبة (مرتبة حسب القالب)
  │   ├── أقسام عادية → باللون العادي
  │   ├── حقول مساعدة → باللون الرمادي (مساعد)
  │   └── صيغ حسابية → باللون الأحمر (محسوب)
  └── المقيّمون
  ↓
يمكنه الطباعة أو التعديل
```

## مثال عملي كامل

### القالب:
```
المعيار: "الأداء الإداري" (وزن 60%)
  ├── A1: "الإنجاز" (percentage، وزن 40%)
  ├── B1: "الجودة" (percentage، وزن 35%)
  ├── C1: "عدد الموظفين" (helper) ← لا يُحتسب
  ├── D1: "الالتزام" (percentage، وزن 25%)
  └── E1: "المتوسط" (formula: =(A1+B1+D1)/3)

المعيار: "القوة التنظيمية" (وزن 40%)
  ├── A2: "القوة الفعلية" (auto: actual_force)
  ├── B2: "القوة المطبقه" (numeric، وزن 100%)
  └── C2: "نسبة المطابقة" (formula: =(A2/B2)*100)
```

### التعبئة:
```
المعيار 1:
  ├── الإنجاز: 85 ← المستخدم يدخل
  ├── الجودة: 90 ← المستخدم يدخل
  ├── عدد الموظفين: 150 ← helper (لا يُحتسب)
  ├── الالتزام: 78 ← المستخدم يدخل
  └── المتوسط: 84.33 ← يُحسب تلقائياً

المعيار 2:
  ├── القوة الفعلية: 150 ← يُملأ من النظام
  ├── القوة المطبقه: 160 ← المستخدم يدخل
  └── نسبة المطابقة: 93.75% ← يُحسب تلقائياً
```

### النتيجة النهائية:
```
الدرجة الإجمالية = (84.33 × 60%) + (93.75 × 40%) = 50.6 + 37.5 = 88.1%
```

## ملاحظات تقنية مهمة

1. **الأمان:** استخدام `addslashes()` لمنع SQL Injection في الاستعلامات
2. **الأداء:** حساب الصيغ على الخادم (PHP) + حساب فوري على العميل (JavaScript)
3. **المرونة:** دعم أي عدد من المعايير والأقسام
4. **التوافق:** يعمل مع جميع أنواع القوالب (موظف، دورة، ورشة، وحدة، إداري)
5. **الطباعة:** `print-style.css` يخفي كل شيء ما عدا `printable-area`
6. **helper:** لا يُحتسب في الوزن لكن يُحسب كعمود في مصفوفة الصيغ
7. **الحساب المتكرر:** FormulaEngine يحسب الصيغ في 3 مرات لدعم الصيغ المعتمدة على صيغ أخرى
