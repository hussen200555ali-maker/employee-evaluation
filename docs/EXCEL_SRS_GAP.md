# فجوة Excel في المشروع المرفق

## الوضع الموجود

| المجال | الدليل في المشروع | الحكم |
|---|---|---|
| تصدير تقييمات XLSX | `app/Services/ExportService.php` ينشئ ورقة واحدة من بيانات عامة. | جزئي ومحدود. |
| تقييد البيانات بالنطاق | `AnalysisController::exportExcel()` يستدعي `getAllForApi()` بلا استخدام للمعاملات `level` و`target_id`. | غير منفذ. |
| صلاحية التصدير | لا يوجد إلا `analysis.view`، ولا توجد صلاحية مستقلة للتصدير أو تحقق تخصيص المقيّم. | غير كافٍ. |
| قالب إدخال نتائج المقيّم | لا توجد ورقة إدخال مقيدة بالمقيّم، ولا معرفات مخفية محمية، ولا تفاصيل البنود. | غير منفذ. |
| استيراد XLSX/CSV | لا توجد خدمة أو متحكم أو مسارات أو واجهة معاينة. | غير منفذ. |
| دفعة الاستيراد وأخطاء الصفوف | مخطط SQL لا يضم جداول دفعات الاستيراد أو أخطاء الصفوف. | غير منفذ. |
| الاعتمادات | `composer.json` لا يعلن `phpoffice/phpspreadsheet` رغم استخدامه في خدمة التصدير. | خلل تثبيت حرج. |

## نطاق الإصلاح الأول

سيضيف الإصلاح الاعتماد المحلي لـPhpSpreadsheet، وترحيلاً لجداول دفعات الاستيراد وأخطاء الصفوف، وخدمة Excel موحدة، ومسارات محمية للتصدير والرفع والمعاينة والالتزام. يرفض الالتزام أي تقييم خارج صلاحية المستخدم أو غير مسودة، ويعيد بناء الإجابات من معرفات الأقسام الموثوقة ثم يحفظها داخل معاملة واحدة مع سجل تدقيق.

> لا يثبت هذا الإصلاح وحده مطابقة SRS الكاملة؛ يبقى نموذج النطاق متعدد المستويات وحالات سير العمل المتقدمة من فجوات المشروع الأساسية.
